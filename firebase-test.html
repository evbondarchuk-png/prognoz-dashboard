Прогноз / тест Firebase
настройка
1
Вставь URL своего Firebase проекта

Зайди на console.firebase.google.com, открой свой проект → Realtime Database → скопируй URL базы.

URL выглядит так: https://prognoz-archive-default-rtdb.europe-west1.firebasedatabase.app

2
Проверяем подключение к Firebase

Нажми кнопку — мы попробуем записать и прочитать тестовые данные.

3
Записываем тестовый архив

Запишем тестовые данные по 3 риэлторам в Firebase, чтобы проверить всю цепочку.

4
Читаем архив и считаем средние

Проверяем что дашборд может прочитать данные и рассчитать аналитику.

5
Всё работает! Следующие шаги

Если все шаги прошли успешно — Firebase настроен и готов к работе.

Теперь нужно:

1. Установить скрипт архивации в Google Sheets (файл firebase-archiver.gs)

2. Настроить ежедневный триггер

3. Обновить дашборд для чтения реальных данных
